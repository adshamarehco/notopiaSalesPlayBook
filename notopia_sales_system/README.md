# سیستم فروش نوتوپیا — نسخه ۱

نرم‌افزار سبک مبتنی بر PHP + MySQL برای اجرای فرآیند فروش نوتوپیا  
منطبق با کتابچه فروش (فصل‌های ۵، ۹ و ۱۳)

---

## پیش‌نیاز روی هاست لینوکس

- PHP 8.0+ (با پسوند PDO و pdo_mysql)
- MySQL 5.7+ یا MariaDB
- دسترسی به phpMyAdmin یا خط فرمان MySQL

---

## نصب در ۵ دقیقه

### ۱. ساخت دیتابیس
در phpMyAdmin یا ترمینال:

```bash
mysql -u USER -p < database.sql
```

یا محتوای `database.sql` را در phpMyAdmin اجرا کنید.

### ۲. تنظیم اتصال
فایل `includes/config.php` را باز کنید و این مقادیر را پر کنید:

```php
define('DB_HOST', 'localhost');
define('DB_NAME', 'notopia_sales');
define('DB_USER', 'نام_کاربری_دیتابیس');
define('DB_PASS', 'رمز_دیتابیس');
define('APP_PASSWORD', 'رمز_ورود_دلخواه');  // حتماً تغییر دهید
```

### ۳. آپلود فایل‌ها
کل پوشه را روی هاست در مسیر دلخواه (مثلاً `public_html/sales` یا ساب‌دامین) آپلود کنید.

### ۴. ورود
آدرس را در مرورگر باز کنید:

```
https://your-domain.com/sales/login.php
```

رمز پیش‌فرض در `config.php` با کلید `APP_PASSWORD` تعریف شده است.

## امکانات نسخه ۱

| صفحه | کار |
|------|-----|
| داشبورد | تعداد فرصت فعال، پیشنهاد ماه، جلسه هفته، گام‌های عقب‌افتاده |

| گزارش هفتگی | مطابق کارت ۵ و فصل ۱۳ + پیشنهاد عدد از داده‌های سیستم |

---

## قواعد مهم استفاده

1. هیچ فرصتی خارج از سیستم وجود ندارد.
2. جلسه / نمایش / پیشنهاد حداکثر تا پایان همان روز ثبت شود.
3. برای فرصت فعال یا در حال پرورش، گام بعدی اجباری است.
4. جلسه بررسی فروش فقط بر اساس داده ثبت‌شده برگزار شود.

---

## امنیت اولیه

- رمز ورود را حتماً عوض کنید.
- پوشه را ترجیحاً روی HTTPS قرار دهید.
- دسترسی فایل `includes/config.php` را محدود نگه دارید.
- پشتیبان‌گیری منظم از دیتابیس را فعال کنید.
